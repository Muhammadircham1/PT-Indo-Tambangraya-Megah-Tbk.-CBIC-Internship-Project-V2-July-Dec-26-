Trus untuk selanjutnya yang perlu kamu setup ada beberapa

A. ganti path Power bi (Jika masih menggunakan PowerBI) :

Di jendela Power BI Desktop, pada tab Home, klik Transform Data, lalu pilih Data source settings.

Pada jendela yang muncul, pilih sumber data yang ingin Anda ubah.

Klik tombol Change Source... di bagian bawah.

Masukkan path baru, lalu klik OK dan Close.

Klik Apply Changes pada notifikasi kuning di bagian atas layar untuk memuat ulang data.
